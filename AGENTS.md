# AGENTS.md — docker-chromium

## What this is
Docker image for running a headless Chromium browser instance.

## Stack
- Docker
- Chromium

## Build
```bash
docker build -t myridia/chromium .
```

## Run
```bash
docker run -d myridia/chromium
```
